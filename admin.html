💾 数据保存机制 — 部署后如何保留作品？
本管理界面管理的是"作品页"（gallery / artwork / artist），不是首页的非卖品展示。 您添加/编辑/删除后立即在作品页可见。数据的保留方式：
  1. localStorage（自动） — 同一浏览器永久保留，无需任何操作。
  2. GitHub 同步（部署后实时生效） — 在下方"GitHub 配置"中填入仓库 + Personal Access Token，保存时自动 commit data/artworks.json。Vercel/Netlify/CloudFlare Pages 监听 push 后几秒到几十秒内自动重新部署，访客刷新即可看到。
  3. 导出 JSON（兜底） — 任何情况下都可点"导出 JSON"下载文件，离线备份或手动部署。
