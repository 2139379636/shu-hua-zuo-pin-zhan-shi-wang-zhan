## 一、题材分类（按描述归纳）

### 1. 漓江山水（核心题材，占绝对主导）

**视觉特征**：
- 漓江烟雨
- 漓江晓雾
- 江岸奇峰耸立
- 行舟顺水流动
- 红帆点点（标志性元素）
- 清江一曲绕山
- 奇峰迎晓日
- 清渡载行舟
- 客望千山翠

**情感特征**：
- 桂林山水的鲜活灵气
- 田园小诗般的温柔
- 文人惬意的优雅
- 不重复的题款，每幅各有千秋

---

### 2. 桂林景点特写

- **同一景点多幅变体**：一个桂林景点画三、五、十张，各有千秋，绝不重复
- 体现画家对桂林的"唯一挚爱"

## 三、详情页文案模板（基于原文风格）

### 标题模板

```
《[作品名]》
桂林山水 · 漓江风情
```

### 详情描述模板

```
这幅[作品名]是画家[创作年份 / 季节]在[地点]的写生创作。

画面以[核心元素]为主体，[构图特点]。
色调[色彩特点]，尽显[意境特点]。

画家在画上题诗：
「[题画诗全文]」

每一段题诗都表达各不相同的心境，
是一种身为游客却超乎寻常的文人惬意。
```

### 底部引言

```
"用诗情表达心声，用心境外化读者。"
—— 黄桂明
```
