# 艺术风格描述（Art Style Description）

> 用于网站"艺术家"页 / "作品"页 的视觉化文案

---

## 一句话风格总结

> **桂林山水的鲜活灵气，在淡彩与重彩之间，在小写意与大写意之间，每一笔都洗练流畅，每一画都满载诗情。**

---

## 详细风格拆解

### 1. 笔法 — 洗练流畅

- 落笔线条**洗练流畅、游刃有余**
- 没有半点的**刻意雕琢和描摹**
- 自然松弛、毫无匠气

### 2. 色彩 — 在两极之间游走

- **淡彩与重彩之间**：不薄不厚，恰到好处
- **小写意与大写意之间**：不拘一格，随心而动
- **色调明丽清新、雅致耐看**

### 3. 构图 — 驾轻就熟

- 画面的**参差错落**
- **虚实呼应**
- **浓淡对比**
- 笔墨间的**干湿变化**
- 拿捏得恰到好处

### 4. 题材 — 唯一而深邃

- **只画桂林山水**（漓江流域）
- 至今未画过其他题材
- 一个景点画三、五、十张，每幅各有千秋
- 桂林是他唯一的挚爱

### 5. 标志性元素（视觉识别）

- 🌫️ **漓江烟雨 / 漓江晓雾** — 水墨朦胧感
- ⛵ **红帆点点** — 漓江标志性点缀
- ⛰️ **奇峰耸立** — 桂林山水的骨架
- 🚣 **行舟顺水** — 动态元素
- 🌸 **春日繁花** — 季节感
- ☁️ **山间薄雾** — 留白美学

## 与现有网页8 项目的契合度

- 设计灵魂："晨光书房，墙上水墨等你读懂"
- 主色：墨色 #1A1A1A + 宣纸米 #F5F1E8
- 强调色：朱砂印章红 #A8332C
- 字体：Noto Serif TC + Noto Sans TC
- 核心交互：双层图片鼠标遮罩效果

### 黄桂明画作的契合点

- ✅ "朱砂印章红" 可用于题款印章视觉元素
